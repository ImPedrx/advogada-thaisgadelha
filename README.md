# Gomes de Carvalho · Sociedade de Advogadas

Site do escritório Gomes de Carvalho (Fortaleza-CE, atuação nacional), das sócias Dra. Séfora Aylla Gomes e Dra. Thaís Carvalho: Direito Civil, Administrativo, Constitucional, Trabalhista e Previdenciário, com consultoria on-line.

React + Vite + Tailwind v4, animações com Motion. Componentes de [React Bits](https://reactbits.dev) (RotatingText, ShinyText, SpotlightCard, CurvedLoop, SplitText, Magnet), botão inspirado no Uiverse e `Pillars` (fundo de linhas com feixes, no estilo dos "background beams" do 21st.dev) próprio. Pensado primeiro para o celular.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # gera dist/
```

Conteúdo editável (sócias, WhatsApps, áreas, situações, etapas, FAQ) em `src/content.ts`. Fontes: Instagram @gomesdecarvalhoadv e linkme.bio, Facebook e Escavador da Dra. Thaís, Google Maps.
Fotos em `public/img/`, tiradas dos posts de apresentação com o texto removido. Originais em `../photos/`.

Antes de publicar, confirmar com as sócias: registro da sociedade e OAB de cada uma (obrigatórios, Provimento 205/2021), itens das áreas Trabalhista e Previdenciária, horário e logo em arquivo.
